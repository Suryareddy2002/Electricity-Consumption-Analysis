# Electricity Consumption Analysis Report

This SQL project provides insights into electricity consumption data. It includes table creation, data insertion, and analytical queries to understand consumption trends, identify high-usage consumers, and more.

## 📁 Project Structure

- `sql_project_Electricity Consumption Analysis Report.sql`: The main SQL script containing the following:
  - Table creation for consumers and consumption records
  - Data insertion for sample consumers and usage
  - Analytical queries for monthly trends, top consumers, and consumption summaries

## 🧠 Objectives

- To create a structured database for electricity usage
- To perform data analysis using SQL queries
- To generate reports and identify consumption patterns

## 🔍 Key SQL Features Used

- `CREATE TABLE`
- `INSERT INTO`
- `JOIN`
- `GROUP BY` and `ORDER BY`
- Aggregate functions like `SUM()`, `AVG()`
- Subqueries and aliases

## 📊 Example Queries

Some of the insights provided:
- Monthly consumption totals
- Top 5 consumers by usage
- Area-wise electricity usage breakdown
- Average consumption over time

## 🛠️ How to Run the Project

1. Open a SQL environment like MySQL Workbench or pgAdmin
2. Execute the `.sql` file to create tables and populate them
3. Run each query block to generate insights
